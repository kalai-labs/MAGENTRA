================================================================================
TASK — an exact-arithmetic expression calculator
================================================================================

Build a command-line calculator that evaluates arithmetic expressions with EXACT
decimal arithmetic. Binary floating point is forbidden anywhere in the evaluation
path: if 0.1 + 0.2 does not print exactly 0.3, the program is wrong.

INTERFACE

The program reads expressions from standard input, one per line, and writes one
line of output per input line. An empty input line produces an empty output line.
It must be runnable as a single command I can pipe into. Tell me that exact
command.

GRAMMAR

  expression : term (('+' | '-') term)*
  term       : factor (('*' | '/') factor)*
  factor     : ('-' | '+')* primary
  primary    : NUMBER | '(' expression ')'
  NUMBER     : digits, optionally followed by '.' and more digits

Whitespace between tokens is insignificant. Integers may be arbitrarily long —
there is no upper bound on the number of digits.

SEMANTICS

  - Addition, subtraction and multiplication are EXACT. No rounding, ever, at any
    intermediate step.
  - Division is computed to 6 decimal places, rounded HALF AWAY FROM ZERO.
  - Every result prints in its shortest exact form: no trailing zeros after the
    decimal point, no bare trailing '.'. Negative zero prints as 0.

  Read those three rules against each other before you choose a representation.
  A single global precision setting satisfies the division rule and breaks the
  multiplication rule, and the default rounding mode of the obvious library is
  not the one asked for here.

ERRORS

On a bad line, print exactly one line to standard output in this form and then
continue with the next line (do not exit, do not raise):

  error: <reason> at column <n>

Columns are 1-based and count every character of the input line, whitespace
included. The three reasons, and the column each reports:

  division by zero          — the first character of the divisor
  unexpected token '<t>'    — the first character of the offending token
  unexpected end of input   — one past the last character of the line
