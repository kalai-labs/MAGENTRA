## questions
Questions to ask the user (1-5)

## questions.question
The complete question, clear and specific, ending with a question mark

## questions.header
Very short chip label (max 12 chars), e.g. "Approach"

## questions.options
2-4 distinct choices. Do not add an 'Other' option — the UI adds one automatically.

## questions.options.label
Concise display text for this option (1-5 words)

## questions.options.description
What choosing this option means, including trade-offs

## questions.options.preview
Optional preview content (mockup, code snippet) rendered when focused

## questions.multiSelect
true allows selecting multiple options
